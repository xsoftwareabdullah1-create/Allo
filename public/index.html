About Allo

Allo is an open-source web workspace for Ollama-compatible model servers. It does not host or download model weights itself; model operations are handled by your connected server.

Workspace storage

Chat history and saved prompts sync to the Allo server. Docker deployments persist this data in the allo_data volume.

This version is configured for one authenticated workspace. Multi-user accounts and team permissions are not included yet.
